# T005: Time and formatting utilities

## Build log — 2026-08-11

Created `lib/time/` module with 10 pure formatting functions for the timer, vine, and grid views:

### Functions implemented:
1. `fmtClock(ts)` — 12-hour format like `2:14 PM` (no leading zero on hour)
2. `dayKey(ts)` — calendar-day key matching `toDateString()` semantics for bucketing entries
3. `fmtDayTitle(ts, now)` — "Today" or long form like `Sunday 9 Aug`
4. `fmtGridDayLabel(ts, index)` — "Today", "Yesterday", or short form like `Sat 8`
5. `fmtTodayLabel(now)` — header date like `Mon 10 Aug`
6. `fmtAwayElapsed(sinceTs, now)` — elapsed time like `43 min` or `7h 12m` (unpadded minutes)
7. `padCount(n)` — zero-padded 2-digit count like `03`
8. `fmtChimeRange(fromTs, toTs)` — range with en dash like `2:14 PM – 3:14 PM`
9. `gridCellTitle(hour, tag, firstBullet)` — full cell label like `14:00 · Comms — Inbox, mostly`
10. `gridCellEmptyTitle(hour)` — empty cell label like `9:00 · not logged`

All functions are pure (take timestamps as arguments, no `Date.now()`), enabling deterministic testing.

### Testing:
- Added 39 comprehensive unit tests covering all functions
- Tested exact output formats including special characters (en dash U+2013, middle dot U+00B7, em dash U+2014)
- Tested 59/60-minute boundary for elapsed time
- Tested unpadded hour formatting (9:00, not 09:00)
