## Completion — 2026-08-11

1. **Dependencies added** (`package.json`):

   - `@testing-library/jest-dom`

4. **Component test created** (`test/rtl-setup.test.tsx`):
   - Uses per-file `@vitest-environment jsdom` directive to run in jsdom
   - Imports `@testing-library/jest-dom/vitest` to load matchers
   - Renders a trivial React component with RTL's `render()`
   - Asserts using jest-dom matcher `toBeInTheDocument()`
   - Stubs and tests `window.matchMedia()` with a minimal MediaQueryList-shaped object

### Design notes

- Environment selection uses per-file directives (`@vitest-environment jsdom`) rather than global environmentMatchGlobs, which proved more reliable
- Default environment is node to protect existing database and server-side tests
- jest-dom matchers and jsdom globals are available only in jsdom tests via test-file imports; node tests are unaffected
- MediaQueryList stub is defined in the test's beforeAll() hook to avoid jsdom polyfill pollution
