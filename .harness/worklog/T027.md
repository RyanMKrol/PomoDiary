# T027 Worklog

## 2026-08-11

### What was done

Implemented responsive layout for screens below 950px width. The two-column desktop layout now stacks vertically on smaller screens with the timer panel on top and the vine (log view) below.

### CSS changes made

1. **Panels.module.css**: Added @media (max-width: 950px) query to:
   - Change grid-template-columns from two-column to single column (minmax(0, 1fr))
   - Change grid-template-rows from single row to two rows (auto 1fr)
   - Replace right border on leftPanel with bottom border
   - leftPanel now takes auto height, rightPanel takes remaining flex space

2. **BulletJotter.module.css**: Added @media (max-width: 950px) query to:
   - Cap .scroller max-height to 40vh to keep picker strip and control bar reachable

3. **Header.module.css**: Added @media (max-width: 720px) query to:
   - Hide tagline (display: none) so wordmark and count never collide on narrow screens

4. **GridView.module.css**: Added @media (max-width: 720px) query to:
   - Shrink day-label column from 88px to 64px in both .rulerRow and .dayRow
