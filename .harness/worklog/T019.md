# T019: Control bar + recap bar

## 2026-08-11

### What I did

Created two button bar components for the timer panel:

1. **ControlBar.tsx + ControlBar.module.css**: Renders in running/paused modes with four buttons:
   - Pause/Resume (flex:1, red #ec3013 swatch, dispatches pause/resume)
   - Restart (no swatch, .55 alpha text, dispatches restart)
   - Sleep (purple oklch(0.38 0.055 275) swatch, dispatches awayStart("sleep"))
   - Work (blue oklch(0.50 0.075 235) swatch, dispatches awayStart("work"))
   - 2px top rule, 2px right dividers, 12px/800/.08em/upper typography

2. **RecapBar.tsx + RecapBar.module.css**: Renders only in recap mode with two buttons:
   - Log it & start the next hour (flex:1, red #ec3013 fill, white text, 10px white swatch, dispatches log with current drafts)
   - Skip (transparent, 2px left rule, .5 alpha, dispatches skip)

Both components:
- Accept useTimer state and dispatch functions
- Hide in chime/away modes
- Use CSS modules for styling per design tokens (Archivo 12px/14px, proper hover states)
- Match design spec exactly: colors, spacing, dividers, swatches
