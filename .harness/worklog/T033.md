# T033 — Security headers (frame-ancestors, nosniff, referrer, permissions)

## 2026-08-11

Completed T033 by implementing standard security headers for the external-facing app.

### Implementation

1. Updated `next.config.ts` to add an async `headers()` function that returns the following headers for all routes (`source: "/(.*)")`):
   - `X-Content-Type-Options: nosniff` — prevents MIME type sniffing
   - `X-Frame-Options: DENY` — prevents clickjacking
   - `Content-Security-Policy: frame-ancestors 'none'` — reinforces frame-ancestors policy
   - `Referrer-Policy: strict-origin-when-cross-origin` — controls referrer information
   - `Permissions-Policy: camera=(), microphone=(), geolocation=()` — disables browser features

2. Created `test/security-headers.test.ts` with comprehensive tests:
   - Verifies the headers configuration exists
   - Validates all five security headers are present in the catch-all route
   - Confirms each header has the correct value
   - Confirms exactly five headers are configured

### Design Notes

Followed the spec precisely by NOT implementing a full `script-src` CSP directive. The current implementation adds only the safe frame-ancestors directive to prevent clickjacking attacks without breaking Next.js inline scripts or Clerk's cross-origin script loading.
