# T018 Worklog

## 2026-08-11

Built the PickerStrip component: a pinned strip below the bullet scroller that includes tag chips, feeling row, and intent row. All five pieces of the spec are implemented:

1. **Strip pinned**: `flex:0 0 auto`, 2px top rule, padding 11/32/13, never inside scroll region.
2. **Label row**: Shows "Call it" + inference hint "↳ reads like {label}" in category color when inference exists and no explicit pick is set.
3. **Tag chips**: All 8 TAGS in order, wrapping flex with 4px gap. Three states:
   - Idle: transparent fill, divider border, 0.7 alpha text
   - Suggested: transparent fill, category color border and text (inferred, not picked)
   - Selected: category color fill, white text (explicit pick)
   - Hover border #ec3013 on all states
   - Click selected chip deselects (back to suggestion if any)
4. **Feeling row**: Full-width 4-segment segmented row (Charged/Steady/Scattered/Drained). Selected state is ink fill (#201e1d) with white text, not color.
5. **Intent row**: Full-width 2-segment row (On purpose/Got away). Stores keys `yes`/`no` not labels. Toggle-off on reclick.

All picks flow through `updateDraft()`. Tag inference is computed on every render from `inferTag(draftBullets)`.
