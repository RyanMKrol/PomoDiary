# T008 — Timer state machine engine (pure, wall-clock driven)

## 2026-08-11

Built `lib/timer/engine.ts`, the pure hour-cycle state machine described in the spec.

### Implementation

- `TimerState` mirrors the T006 `timerState` row shape but uses plain millisecond
  epoch numbers instead of `Date` (no I/O in this module — `now` is always a
  parameter, never `Date.now()`).
- `deriveNow(state, settings, now)` — lazy wall-clock reconstruction: if `running`
  and the session has elapsed, derives `chime` with the *original* hour span
  (`chimeFrom = hourStart`, `chimeTo = hourStart + sessionMs`), not `now`. Also
  derives `remainingSeconds` for running (floored at 0) and paused (verbatim
  `pausedRemaining`).
- `dispatch(state, settings, action, now)` implements every action from the spec:
  `pause`, `resume` (rebases `hourStart` from the frozen `pausedRemaining`),
  `restart` (preserves drafts, does not advance `phraseIdx`), `ringNow`, `acknowledge`,
  `log` (trim/drop-empty bullets, tag inference fallback, em-dash feel fallback, null
  intent, "(nothing written down)" fallback), `skip` (same reset, no entry),
  `awayStart`/`awayReturn` (1h-block backfill loop with the 60s-remainder-drop and
  24-block hard cap, newest-first), and `draftUpdate`. Each action validates its own
  legal starting mode and is a no-op (returns the literal input `state`) otherwise.
- `initialState(now)` for a first-time user.
- Only imports from `lib/domain` (`AWAY`, `inferTag`) — no React/Next/`lib/db`.

### Tests

`lib/timer/engine.test.ts` — 42 tests covering the full transition matrix: every
action's happy path and its no-op set for every illegal starting mode, the
closed-laptop chime derivation (3h elapsed still reports the original 1h span),
pause/resume rebase arithmetic (verified round-trip through `deriveNow`), restart's
draft preservation + phraseIdx-not-advanced, log's every fallback path individually,
skip's phraseIdx-does-advance (contrasted with restart), and all four away-backfill
boundary cases (90min → 1h+30min, 60min30s → exactly one 1h block, 45s → nothing,
30h → exactly 24 blocks with the newest block ending at 24h).
