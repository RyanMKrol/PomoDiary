# T040 Worklog

## 2026-08-11

### What was done

Completed T040: created `lib/notify/` module with title/favicon swap and system notifications for hourly chime.

**Implementation:**
1. **lib/notify/index.ts** - Core module with four functions:
   - `setChimeTitle(on: boolean)` - Sets page title to "⏰ Time's ripe — PomoDiary" when chiming, restores original when false
   - `setChimeFavicon(on: boolean)` - Swaps favicon to red accent variant while chiming, restores original
   - `requestNotifyPermission()` - Requests browser notification permission via Notification API
   - `notifyChime(fromTs, toTs)` - Posts system notification only when permission is granted AND page is hidden (not when visible)

2. **lib/notify/index.test.ts** - Comprehensive jsdom test suite (16 tests):
   - Title management: set/restore, multiple toggles
   - Favicon management: swap to accent, restore original, multiple toggles, handles missing favicon link
   - Permission: requests permission, does nothing if Notification undefined
   - Notification posting: only when permission granted AND page hidden, never when visible, sets onclick to focus window

3. **lib/client/useTimer.ts** - Wired notify functions into timer client:
   - On chime event: calls `setChimeTitle(true)`, `setChimeFavicon(true)`, and `notifyChime(fromTs, toTs)`
   - On mode exit from "chime": clears title/favicon with `setChimeTitle(false)`, `setChimeFavicon(false)`
   - On first user action: calls `requestNotifyPermission()` (tracked with `hasRequestedNotifyPermission` flag)

4. **app/layout.tsx** - Added favicon metadata linking to public/favicon.svg

5. **public/** - Created favicon variants:
   - `favicon.svg` - Default light gray square
   - `favicon-accent.svg` - Red variant (#dc2626) for chime state
