# T004 — Domain vocabulary module

## 2026-08-11 — Initial implementation

### What was done

Created `lib/domain/index.ts` with all required typed constants and functions:

1. **TAGS** - Array of 8 tag objects with exact order and OKLCH colors from prototype lines 250–281:
   - Deep work, Admin, Meetings, Comms, Learning, Errands, Rest, Lost it
   - All keywords transcribed verbatim including "procrastin", "x", "followed up", "school run", "not sure", "no idea"

2. **UNFILED_COLOR** - `"oklch(0.72 0.012 40)"`

3. **tagColor(label)** - Lookup function returning tag colors, AWAY colors, or UNFILED_COLOR fallback

4. **AWAY** - Object with `sleep` and `work` configs containing tag, color, end, title, note, bullet (omitted unused `start` field)

5. **FEELS** - Array of 4 feeling labels: Charged, Steady, Scattered, Drained (omitted unused `dots` field)

6. **INTENTS** - Object mapping yes → "On purpose", no → "Got away"

7. **PHRASES** - Array of 5 [phrase, subPhrase] pairs

8. **inferTag(bullets)** - Function reproducing prototype logic exactly:
   - Joins bullets with space and lowercases
   - Returns null if text length < 3
   - Scores each TAGS category by substring includes (+2 for >5 char keywords, +1 otherwise)
   - Returns earliest category on tie, null if score is 0

### Tests created

Comprehensive test suite in `lib/domain/index.test.ts` covering:
