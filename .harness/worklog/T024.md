# T024: The vine: 10-day grid view with ruler and legend

## 2026-08-11

### What I did

Created the GridView component that displays a 10-day grid by 24 hours:

1. **GridView.tsx** - Main component that:
   - Fetches entries for a 10-day range (9 days ago through today)
   - Buckets entries by day and start hour client-side
   - Renders a ruler row with hour labels (00, 03, 06, 09, 12, 15, 18, 21)
   - Displays 10 day rows, each with day label, 24 hour cells, and count
   - Cells are colored based on entry tag, with empty cells in #e6e3e3
   - Each cell has a title showing hour, tag, and first bullet
   - Rows are clickable to select a day and return to day view
   - Legend below showing all 10 categories (8 TAGS + Asleep + At work, no Unfiled)
   - Footer text: "Click a day to read the hours back."

2. **GridView.module.css** - Styling with:
   - Grid layout `88px 1fr 42px` with 14px gap for rows

   - Hover and selected state background #eae9e9
   - Legend with 11px squares and labels
   - riseIn 0.4s animation on row hover

3. **Updated Vine.tsx** to:

### How it works

1. GridView calculates 10 days starting from today going backwards
2. Fetches entries for the full 10-day range via `/api/entries?from=&to=`
3. Buckets entries by day using dayKey() and by start hour
4. First entry per hour wins when collisions occur
5. Cells display entry color or empty grey
6. Clicking a day row sets selectedDayIndex and switches back to day view
7. Vine component now passes view title as "Every day" when in grid mode
