## Overview

Pure time/formatting helpers used across the timer, the vine, and the grid — all the exact
string formats the design specifies, in one tested module.

## Do

Create `lib/time/` with pure functions (no Date.now() inside — take timestamps as arguments so
tests are deterministic):

1. `fmtClock(ts)`: 12-hour time like `2:14 PM` (no leading zero on the hour, upper-case AM/PM) —
   matches the prototype's `fmt`.
2. `dayKey(ts)`: a calendar-day key equivalent to JS `new Date(ts).toDateString()` semantics
   (local time), used to bucket entries into days.
3. `fmtDayTitle(ts, now)`: day-view title — `Today` when same local day as `now`, else long form
   like `Sunday 9 Aug` (`weekday:"long", day:"numeric", month:"short"`).
4. `fmtGridDayLabel(ts, index)`: grid row label — `Today` (index 0), `Yesterday` (index 1), else
   short form like `Sat 8` (`weekday:"short", day:"numeric"`).
5. `fmtTodayLabel(now)`: header date like `Mon 10 Aug` (`weekday:"short", day:"numeric", month:"short"`).
6. `fmtAwayElapsed(sinceTs, now)`: `43 min` under an hour, else `7h 12m` — minutes NOT
   zero-padded (`7h 5m`).
7. `padCount(n)`: zero-padded 2-digit count (`03`, `00`) for hours-logged counts.
8. `fmtChimeRange(fromTs, toTs)`: `2:14 PM – 3:14 PM` — the separator is space + EN DASH (U+2013)
   + space.
9. `gridCellTitle(hour, tag, firstBullet)`: `14:00 · Comms — Inbox, mostly` — hour NOT
   zero-padded (`9:00 · …`), separators are ` · ` (U+00B7) and ` — ` (em dash). Also
   `gridCellEmptyTitle(hour)`: `9:00 · not logged`.

Unit-test each format with fixed timestamps, including the away-elapsed 59/60-minute boundary
and the unpadded-hour grid title.

## Done when

`npm test` passes; every listed function exists with the exact output shapes above (assert the
literal strings, including the en dash and middle dot, in tests).
