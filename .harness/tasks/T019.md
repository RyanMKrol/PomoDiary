## Overview

The bottom bars of the timer panel: the four-button control bar (Pause/Resume · Restart ·
Sleep · Work) while the clock runs, and the recap bar (Log it / Skip) during recap.

## Do

Create `components/ControlBar.tsx` + `components/RecapBar.tsx` on `useTimer`. Reference:
`design/README.md` "Left panel d./e.", prototype lines 114–136:

1. Control bar (rendered only in running/paused): 2px top rule; four buttons, all
   12px/800/.08em/upper, padding 15px 16px, 2px right dividers, flush-LEFT labels with a 9px
   square swatch and 9px gap:
   - `Pause`/`Resume` (label from mode), `flex:1`, red `#ec3013` swatch, hover
     `#ffe0d9`/`#ae1800`; dispatches pause/resume.
   - `Restart` — NO swatch (the README's "outline swatch" is wrong; the prototype has none),
     `.55` alpha text, hover `#eae9e9`/`#201e1d`; dispatches restart.
   - `Sleep` — 9px swatch `oklch(0.38 0.055 275)`; dispatches `awayStart("sleep")`.
   - `Work` — 9px swatch `oklch(0.50 0.075 235)`; dispatches `awayStart("work")`.
2. Recap bar (recap mode only): `Log it & start the next hour` — accent `#ec3013` fill, white,
   `flex:1`, padding 19px 22px, 14px/.1em, 10px white swatch, hover `#dd2b0f` — dispatches
   `log` with the current drafts; `Skip` — transparent, 2px LEFT rule, 13px, `.5` alpha, hover
   `#eae9e9`/`#201e1d` — dispatches `skip`.
3. In chime mode NEITHER bar renders (the overlay owns the panel).
4. RTL tests: bar presence per mode (running/paused → control, recap → recap, chime → neither);
   Pause↔Resume label flips with mode; each button dispatches its action; Restart has no
   swatch; Log it passes the drafts.

## Done when

`npm test` passes with the per-mode rendering and dispatch suite; labels, swatches, and hovers
match the design exactly.
