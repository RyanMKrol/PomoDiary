## Overview

The accessibility pass the designer scoped as open work: the overlays announce themselves to
screen readers, the grid cells get real accessible names, the bullet inputs get labels, and
the ambient animations respect reduced-motion.

## Do

1. Live regions: a visually-hidden `aria-live="assertive"` region announcing transitions —
   entering chime (`Time's ripe. {range}. Click anywhere to account for the hour.`), entering
   away (`Asleep since {time}` / `At work since {time}`), and returning (`Back. {n} hours
   logged.`). The chime overlay button itself gets an `aria-label` matching its full copy.
2. Grid cells: each cell becomes focusable ONLY via its row (the row is the interactive
   element) — give every cell `role="img"` (or a `<td>`-appropriate role if you restructure)
   with `aria-label` equal to its existing `title` text, and each day row an `aria-label` like
   `Saturday 8, 3 hours logged. Open day.`.
3. Bullet inputs: `aria-label` per row (`Bullet {n} for this hour`); the jotter list is a
   labelled group. Picker rows: the tag chip group, feel row, and intent row each become
   `role="radiogroup"`-style groups with `aria-pressed`/`aria-checked` on options (chips keep
   toggle-off behaviour — use `aria-pressed`).
4. `prefers-reduced-motion: reduce` disables `breathe`, `ringPulse`, `riseIn`, `wipeIn`,
   `barGrow`, `popDot` (keep instant transitions).
5. Focus order sanity: acknowledge → focus lands on the last bullet input (already T017
   behaviour — assert it); closing settings returns focus to the settings button.
6. RTL tests: live region text on each transition; grid cell aria-labels match their titles;
   every input has an accessible name (`getByLabelText` finds each bullet); chip groups expose
   pressed state; reduced-motion class/media application.

## Done when

`npm test` passes with the a11y suite; every interactive element has an accessible name; the
three transition announcements fire; animations are suppressed under reduced motion.
