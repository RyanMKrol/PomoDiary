## Overview

A non-blocking dependency-vulnerability check in CI, so a vulnerable package surfaces in the
build log without ever turning the gate red (the pattern used in the owner's local-jobs
repo).

## Do

1. In `.github/workflows/ci.yml`, after the `Install` step, add:

   ```yaml
   - name: Audit dependencies (non-blocking)
     run: npm audit --omit=dev --audit-level=high || true
   ```

   Keep every existing step untouched; the `|| true` is the point — this step may never fail
   the workflow.
2. Nothing else changes: no new scripts, no local DoD change.

## Done when

CI on the branch is green and its log shows the audit step ran; the step exits 0 even when
`npm audit` reports findings (the `|| true` is present); all pre-existing CI steps are
byte-identical.
