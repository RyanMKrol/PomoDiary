## Overview

The right panel's day view — "the vine": the scrolling newest-first list of logged hours with
their chips and bullets, the panel header with the zoom button, and the empty state.

## Do

Create `components/Vine.tsx` (panel header + view switching state `day|grid`, selected day) and
`components/DayView.tsx`. Data via `GET /api/entries?from=&to=` — the client computes the
selected day's local start/end bounds with `lib/time` and passes explicit ms bounds (the
server never derives calendar days; refetch after every logged entry — key off `useTimer`'s
state changes). Reference: `design/README.md` "Right panel" +
prototype lines 162–170, 209–243:

1. Panel header: 54px, 2px bottom rule, 26px left padding — `The vine` (11/800/.16em/upper) ·
   view title 19px/800 (`Today`, or `Sunday 9 Aug` via `fmtDayTitle`, or `Every day` in grid) ·
   spacer · full-height zoom button with 2px LEFT rule reading `Zoom out` (day) /
   `Back to the day` (grid), with a 9px square outlined in currentColor.
2. Day view: scrolling list, 26px side padding, newest-first (server order). Each entry an
   `<article>` grid `108px 1fr`, 22px gap, 22px vertical padding, 2px bottom rule, entering
   with `riseIn .5s cubic-bezier(.2,.7,.3,1)`:
   - Left: start time 19px/800 (`fmtClock`) · `to {fmtClock(e.to)}` (11/600/.12em/upper/.45) ·
     a 4px bar in `tagColor(e.tag)`.
   - Right: chip row (all chips 3px 9px padding, 11px/800/.09em/upper) — tag chip filled with
     its colour, white text, 2px border same colour; feel chip outline `.35` border, `.65`

     Then the bullet list: 7px square markers in the entry colour offset `translateY(-2px)`,

4. RTL tests (mock fetch): renders entries newest-first with formatted times; intent chip
   variants (Intentional / Got away filled / Unmarked); away entry shows the `—` feel chip;
