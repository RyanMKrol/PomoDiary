## Overview

Put the whole app behind sign-in with Clerk: route-protecting middleware, the ClerkProvider,
sign-in/sign-up pages, and a single `getUserId()` helper every API route will use. Also make CI
builds pass without real keys via a well-formed dummy publishable key.

## Do

1. Add dep `@clerk/nextjs` (v7 / Core 3 — note `auth()` and `clerkClient()` are async).
2. Middleware (`middleware.ts`, or `proxy.ts` if this Next version expects the renamed file —
   check what `next build` accepts): `clerkMiddleware` with `createRouteMatcher` protecting
   EVERYTHING except `/sign-in(.*)` and `/sign-up(.*)` — protected routes call
   `await auth.protect()`. Use the standard matcher config from Clerk's Next.js quickstart
   (skips `_next` internals/static files, always runs for `/api`).
3. `app/layout.tsx`: wrap in `<ClerkProvider>`. `app/sign-in/[[...sign-in]]/page.tsx` and
   `app/sign-up/[[...sign-up]]/page.tsx` rendering `<SignIn />` / `<SignUp />`.
4. `lib/api/auth.ts`: `getUserId(): Promise<string>` — wraps Clerk's
   `const { userId } = await auth()`; throws a typed `UnauthorizedError` when null. ALL later
   API routes get identity from this one function, never from Clerk directly.
5. CI: `next build` prerenders pages under ClerkProvider and fails without a publishable key.
   Add to the `Build` step in `.github/workflows/ci.yml` an `env:` with
   `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY` set to a well-formed dummy test key (format:
   `pk_test_` + base64 of `clerk.example.com$` — no trailing padding issues; verify locally
   that `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=<dummy> npm run build` passes with no other Clerk
   env). Do not add any secret to CI.
6. Update `.env.example` with the Clerk variable names (names only).

## Done when

With real keys in `.env.local`, `npm run dev` redirects `/` to sign-in when signed out and
shows the placeholder page when signed in; `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=<the dummy>
npm run build` passes with no other Clerk env set; CI is green on the branch;
`lib/api/auth.ts` exports `getUserId`.
