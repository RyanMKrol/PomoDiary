## Overview

The assertion-based twin of the visual harness: a clock-injected Playwright script that
fast-forwards through the core temporal flows and FAILS if the behaviour is wrong — the
analogue of the skeleton-shift check in the owner's other repos, aimed at this app's real
risk: time.

## Do

Create `scripts/flow-check.mjs` reusing `_visual-harness.mjs` (same port 4795, same
`E2E_BYPASS_AUTH` seam) but with STATEFUL API fixtures: an in-memory fixture server state that
the intercepted `/api/state`, `/api/timer`, `/api/entries` handlers mutate via the REAL
`lib/timer` engine (import it into the fixture layer), so the browser drives true
transitions. Use Playwright's `page.clock` to control time. Assert, with hard failures:

1. Hour rollover: install the clock, load the app running, fast-forward past the hour → the
   chime overlay appears; the shown range's end equals hourStart + session length (not
   "now") after an extra 30 fast-forwarded minutes of waiting at the chime.
2. Recap + log: click through the chime, type two bullets, pick no tag (let one bullet contain
   `inbox` so inference fires), log it → a day-view entry appears with tag `Comms`, the ring
   resets to empty, and the header count increments.
3. Skip: ring now → acknowledge → skip → no new entry, phrase text changed.
4. Away backfill: start Sleep, fast-forward 3h20m, return → exactly 3 new `Asleep` entries
   (the 20-minute remainder becomes the 4th partial block per the engine: from+1h steps — 3
   full hours + one 20m block = 4 entries; assert 4) and the timer is running again.
5. Pause survives reload: pause, reload the page → still paused with the same remaining
   (fixture state persists across reload).
6. `package.json` script `"flow:check": "node scripts/flow-check.mjs"`; not in CI.

## Done when

`npm run flow:check` exits 0 on a clean checkout with no env vars, and deliberately breaking
an assertion (e.g. editing the expected entry count) makes it exit non-zero; the fixture
layer drives the real `lib/timer` engine rather than reimplementing transitions.
