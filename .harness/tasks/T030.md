## Overview

Wire the T029 visual harness into the build loop so frontend tasks get an "actually look at
it" gate: set `VISUAL_VERIFY_HOOK` in the harness config and confirm it fires. This edits
`.harness/**`, so it is a human step by policy.

## Do

1. In `.harness/config/harness.env`, set:
   `: "${VISUAL_VERIFY_HOOK:=npm run visual:check}"`
   (replacing the empty default; leave the back-compat line and the
   `VISUAL_VERIFY_WORKTYPES`/`LAYERS`/`SKIP_WORKTYPES` defaults as they are — `frontend` layer
   and `component`/`style` work-types already match this backlog's facets).
2. Run `npm run visual:check` yourself once and eyeball the screenshots in
   `scripts/visual-out/` against `design/PomoDiary.dc.html` opened in a browser — this is the
   moment to catch any drift the automated checks can't see.
3. Commit and push the `harness.env` change.

## Done when

`harness.env` carries the hook; a manual `npm run visual:check` run passes and the screenshots
look right against the prototype. Then mark done: `.harness/scripts/mark-done.sh T030`.
