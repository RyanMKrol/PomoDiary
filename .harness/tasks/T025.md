## Overview

A small settings surface for the four persisted preferences: session length, sound on/off,
chime volume, and pause-after-log. The prototype exposed these as editor tweaks; the product
needs a real control, styled inside the Modernist system.

## Do

1. `components/SettingsPanel.tsx`: a flat panel that opens from a small `Settings` text button
   in the vine panel header (right of the zoom button, same 2px-left-rule full-height button
   treatment, 12px/800/upper). The panel overlays the right panel top (no rounded corners, no
   shadow — a `#f3f2f2` sheet with a 2px `rgba(32,30,29,.4)` border), containing:
   - `Session length` — a numeric input, minutes, clamped 1–180 (default 60), 2px-bordered
     square field.
   - `Sound` — a 2-segment On/Off row (selected = ink `#201e1d` fill, white text — same
     treatment as the feel picker).
   - `Volume` — a 5-step segmented row (0 / 0.25 / 0.5 / 0.75 / 1), selected = ink fill.
   - `Start next hour paused` — a 2-segment row: `Start at once` / `Wait for me`.
   Labels 11px/800/.16em/upper like the design's section labels.
2. Persist via `useTimer.updateSettings` (PATCH `/api/settings`); values reflect server state
   on load. Changing session length applies from the NEXT hour (the engine already reads
   settings only when deriving/starting — do not restart the current hour).
3. Close on outside click or the same header button; the panel must not exceed the right
   panel's width.
4. RTL tests: opens/closes; each control PATCHes the right payload; out-of-range minutes are
   clamped before submit; reflects fetched settings.

## Done when

`npm test` passes with the settings suite; all four preferences round-trip through the API;
the panel uses only Modernist styling (zero radius, no shadows, segmented ink selections).
