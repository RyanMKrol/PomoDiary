## Overview

The pinned picker strip: tag chips with the three-state suggested/selected/idle treatment and
the inferred-tag hint, plus the feel and intent segmented rows.

## Do

Create `components/PickerStrip.tsx` on `useTimer`. Reference: `design/README.md` "Left panel
c." + "Tag inference", prototype lines 87–112 and renderVals lines 561–590:

1. Strip pinned below the scroller (`flex:0 0 auto`), 2px top rule, padding 11/32/13 — never
   inside the scroll region.
2. Label row: `Call it` (11/800/.16em/upper/.55) and — only when there is an inference and NO
   explicit pick — `↳ reads like {label.toLowerCase()}` (U+21B3 prefix) coloured in that
   category's colour. Inference comes from `inferTag(draftBullets)` (lib/domain) recomputed on
   render.
3. Tag chips in TAGS order, wrapping flex, 4px gap; 11px/800/upper, padding 5px 9px, 2px
   border. Three states: idle = transparent fill, `rgba(32,30,29,.3)` border, `.7` alpha text;
   suggested (inferred, not picked) = transparent fill, border AND text in the category colour;
   selected = filled with the category colour, white text. Hover border `#ec3013`. Clicking a
   selected chip DESELECTS (back to the suggestion, if any). Explicit pick always beats the
   suggestion.
4. Feeling row: full-width 4-segment row — Charged / Steady / Scattered / Drained — 2px border
   and 2px inner dividers `rgba(32,30,29,.3)`, 10px/800/upper; selected = `#201e1d` fill, white
   text (ink, never colour). Toggle-off on reclick. Intent row below it, same treatment, 2
   segments: `On purpose` / `Got away` — stores the KEYS `yes`/`no` (not labels). Each row is
   its own grid row (they must never sit side by side).
5. All picks flow through `updateDraft`.
6. RTL tests: suggestion appears from typed bullets and disappears once a chip is picked;
   pick beats suggestion; reclick deselects; suggested-vs-selected chip styling differs; intent
   stores `yes`/`no`; feel selected state is ink-filled.

## Done when

`npm test` passes with the chip-state suite; the strip stays pinned (not inside the bullet
scroller); inference display matches `↳ reads like comms` exactly.
