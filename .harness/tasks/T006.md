## Overview

The persistence foundation: Drizzle ORM schema for entries, per-user timer state, and settings
on Neon Postgres, with checked-in SQL migrations, a build-safe lazy client, and a hermetic
PGlite test harness so no test can ever touch a real database.

## Do

1. Add deps: `drizzle-orm`, `@neondatabase/serverless`, dev deps `drizzle-kit`,
   `@electric-sql/pglite`.
2. `lib/db/schema.ts` — three tables, every row keyed by the Clerk user id (`userId: text`):
   - `entries`: `id` (uuid or bigint identity), `userId`, `from`/`to` (timestamptz), `tag` (text),
     `feel` (text), `intent` (text, nullable — stores `yes`/`no`/null), `bullets` (jsonb,
     `string[]`), `createdAt`. Index on `(userId, from)`.
   - `timerState`: one row per user (`userId` primary key): `mode` (text:
     running|paused|chime|recap|away), `hourStart` (timestamptz), `pausedRemaining` (integer
     seconds, nullable), `chimeFrom`/`chimeTo` (timestamptz nullable), `awayKind` (text nullable),
     `awaySince` (timestamptz nullable), `draftBullets` (jsonb `string[]`), `draftTag`/`draftFeel`/
     `draftIntent` (text nullable), `phraseIdx` (integer), `updatedAt`.
   - `userSettings`: `userId` primary key, `sessionMinutes` (integer, default 60), `soundOn`
     (boolean, default true), `chimeVolume` (real, default 0.8), `pauseAfterLog` (boolean,
     default false).
3. `lib/db/index.ts` — LAZY client init (a plain `getDb()` memoizing function, NOT a Proxy
   wrapper): `neon(process.env.DATABASE_URL!)` + `drizzle-orm/neon-http`, constructed on first
   call so `next build` never evaluates it without env.
4. `lib/db/test-db.ts` — test-only helper that builds a Drizzle instance over an in-memory
   PGlite (`drizzle-orm/pglite`) and applies the migrations; guard it: it must throw if
   `DATABASE_URL` would be used, and `getDb()` must throw with a clear message when called in a
   test context (detect vitest via `process.env.VITEST`), so tests can never reach a real DB.
5. `drizzle.config.ts` + generate the SQL migration into `drizzle/` with
   `npx drizzle-kit generate` and COMMIT the generated SQL. Add package scripts
   `"db:generate": "drizzle-kit generate"` and `"db:migrate": "drizzle-kit migrate"`.
6. Tests (colocated, against the PGlite harness): migrations apply cleanly; insert/read an entry
   round-trips `bullets` as `string[]`; `timerState` upsert works; `getDb()` throws under vitest.

## Done when

`npm test` passes with the PGlite-backed tests and no test reads `DATABASE_URL`; `npm run build`
passes with no DB env vars set; the `drizzle/` migration SQL is committed; `getDb()` in a vitest
context throws.
