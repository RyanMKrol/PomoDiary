## Overview

Make the vine editable: fix up a past hour's bullets, tag, feeling, or intent from the day
view, saved through the entries PATCH API. The designer left the vine read-only; this recreates
the timer panel's own editing idioms inline so nothing new is invented visually.

## Do

1. In the day view, each entry gets an `Edit` affordance: a small text button (11px/800/upper,
   `.45` alpha, hover `#ec3013`) at the right end of the chip row.
2. Clicking it swaps the entry body into edit mode, reusing the existing input idioms:
   - bullets become the same borderless inputs as the jotter (same Enter-inserts-after /
     Backspace-removes-empty semantics — reuse/extract the T017 row logic rather than
     duplicating it);
   - the chips become the same three-state tag chip row and feel/intent segmented rows as the
     picker strip (reuse the T018 components with local state).
3. A bottom row inside the editing entry: `Save` (accent fill, white, flush-left) and `Cancel`
   (transparent, 2px left rule). Save PATCHes `/api/entries/[id]` with only the changed
   fields; on success the entry re-renders read-only with the server's copy; on 422 (caps) an
   inline error line in accent red appears and the edit stays open. Cancel discards.
4. Empty-bullet handling on save mirrors the engine: trimmed, empties dropped, all-empty
   becomes `["(nothing written down)"]`.
5. Only one entry editable at a time; entering edit mode on another closes the first
   (discarding unsaved changes).
6. RTL tests: edit swap in/out; save PATCHes only changed fields and re-renders; cancel
   discards; 422 shows the inline error and preserves the draft; the all-empty fallback; the
   one-at-a-time rule.

## Done when

`npm test` passes with the editing suite; a logged hour's tag, feel, intent, and bullets can
each be changed and persist across a reload (via the PATCH API); visual language reuses the
existing chip/segment/input components.
