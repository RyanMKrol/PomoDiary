## Overview

The heart of the app: a PURE timer state machine — `(state, settings, action, now) → { state,
entriesToInsert }` — implementing the hour cycle, pause/resume, restart, chime, recap,
log/skip, and away modes exactly as the prototype does, but wall-clock driven so a closed
laptop never stops the hour. No I/O, no Date.now() inside: `now` is always a parameter.

## Do

Create `lib/timer/engine.ts` (+ types). State shape mirrors the T006 `timerState` row (mode,
hourStart, pausedRemaining, chimeFrom, chimeTo, awayKind, awaySince, draft bullets/tag/feel/
intent, phraseIdx). Reference behaviour: `design/README.md` "Interactions & behaviour" and the
prototype logic `design/PomoDiary.dc.html` lines 335–490. Implement:

1. `deriveNow(state, settings, now)` — lazy wall-clock reconstruction used on every read: when
   `mode === "running"` and `now >= hourStart + sessionMs`, the derived state is `chime` with
   `chimeFrom = hourStart` and `chimeTo = hourStart + sessionMs` (NOT `now` — a chime that sat
   unacknowledged for hours still logs the original hour). `remainingSeconds` is derived:
   running → `sessionMs/1000 - (now - hourStart)/1000` floored at 0; paused → `pausedRemaining`.
2. Actions (each validates it is legal in the current mode; illegal actions are no-ops returning
   the input state):
   - `pause` (running → paused, freeze `pausedRemaining`), `resume` (paused → running, rebase
     `hourStart = now - (sessionMs - pausedRemaining*1000)` so the wall-clock derivation stays
     correct).
   - `restart` (running|paused → running): reset `hourStart = now`; PRESERVES draft
     bullets/tag/feel/intent, does NOT advance phraseIdx (prototype `onReset`, line 669).
   - `ringNow` (running|paused → chime): `chimeFrom = hourStart`, `chimeTo = now`. No-op in
     chime/recap/away (prototype guard, lines 388–397).
   - `acknowledge` (chime → recap).
   - `log(payload {bullets, tag, feel, intent})` (recap|chime → running|paused): builds the
     entry — trim bullets, drop empties, all-empty becomes `["(nothing written down)"]`; stored
     tag is `payload.tag || inferTag(rawUntrimmedBullets) || "Unfiled"`; feel falls back to
     `"—"` (em dash); intent stays null when never picked. `from = chimeFrom ?? hourStart`,
     `to = chimeTo ?? now`. Then reset: mode `paused` if `settings.pauseAfterLog` else
     `running`, `hourStart = now`, clear chime span + drafts, `phraseIdx = (phraseIdx+1) % 5`.
   - `skip`: identical reset, NO entry, phraseIdx still advances.
   - `awayStart(kind)` (running|paused → away): record `awaySince = now`; drafts survive.
   - `awayReturn` (away → running): backfill blocks walking from `awaySince` in 1-hour steps —
     `while (now - from > 60_000 && blocks.length < 24) { to = min(from + 1h, now); push
     {from, to, tag: AWAY[kind].tag, feel: "—", intent: "yes", bullets: [AWAY[kind].bullet]};
     from = to }` — the loop guard silently drops any trailing remainder ≤ 60s and hard-caps at
     24 blocks; return newest-first. Then a clean hour: ALWAYS `running` (ignores
     pauseAfterLog), phraseIdx does NOT advance, drafts cleared.
   - `draftUpdate({bullets?, tag?, feel?, intent?})` — patch drafts in any non-away mode.
3. `initialState(now)` for a first-time user: running, hourStart=now, empty drafts, phraseIdx 0.

Exhaustive unit tests (this is the most test-critical module in the app): every transition,
every illegal-action no-op, the wall-clock chime derivation (including "laptop closed for 3
hours" → chime with the original hour span), pause/resume rebase arithmetic, restart
preservation, log fallbacks (tag inference on raw bullets, feel em dash, null intent,
nothing-written-down), skip-no-entry, phrase advance rules (log/skip yes; restart/awayReturn
no), and away backfill: 90 min → 1h + 30min blocks; 60min30s → exactly one 1h block; 45s →
nothing; 30h → exactly 24 blocks.
